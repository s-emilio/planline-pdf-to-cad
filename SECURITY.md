# Security

Planline processes architectural drawings, which may be confidential.

- The default server binds only to `127.0.0.1`.
- Do not expose the development server directly to the public internet.
- Temporary jobs are stored under the operating system's temporary directory.
- Delete jobs in the app when they are no longer needed.

Please report security issues privately to the repository owner rather than
opening a public issue containing sensitive plans or exploit details.
